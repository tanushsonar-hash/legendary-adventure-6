# Dustline

A self-contained, browser-playable open-world co-op shooter. Open `index.html` in a modern browser; no install or build step is needed.

## Play

- **Runner 1:** WASD to move, mouse to aim, hold **F** or the mouse button to fire.
- **Runner 2:** Arrow keys to move and hold **/** to fire (automatically aims at the nearest hostile).
- Press **E** near an unoccupied car to get in; press **E** again to get out. Drive with your usual movement keys. Cars are faster than running, but avoid buildings and trees.
- Recover all three glowing radio caches, then get both runners inside the marked extraction zone.
- If both runners go down, press **R** to redeploy. Press **R** at any time during a run to restart it.

This version implements local co-op for two players sharing a keyboard. It does not include online multiplayer or network matchmaking.
