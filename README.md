# Dustline

A small, self-contained, browser-playable open-world co-op shooter. No install or build step is required: open `index.html` in a modern browser.

## Play

- **Runner 1:** WASD to move, mouse to aim, hold **F** or the mouse button to fire.
- **Runner 2:** Arrow keys to move, hold **/** to fire (aims at the nearest hostile).
- Recover all three glowing radio caches, then get **both** runners inside the marked extraction zone.
- If both runners go down, press **R** to redeploy. Press **R** at any time during a run to restart it.

This version implements local co-op on one keyboard; it does not use a network server or provide online matchmaking. The game world, mission, enemies, map, and art are all generated in the page.
